Integration Helper by RV Privacy Policy

Last updated: October 28, 2026. This policy covers Integration Helper by RV, previously named SAP Integration Helper, including its publisher-operated remote MCP service.

1. Operator and contact

Integration Helper by RV is independently operated by Rameshkumar Varanganti through Agentic Integration Hub. It provides enterprise integration guidance for developers, architects, and technology leaders. It is not affiliated with, sponsored by, or endorsed by SAP SE, OpenAI, Microsoft, or other technology vendors.

For privacy questions or requests, use the contact page. Do not include passwords, tokens, confidential source code, or personal business records in a privacy inquiry.

2. ChatGPT and the remote service

The plugin supplies instructions and reference material within ChatGPT. When a remote MCP tool is invoked, its arguments are transmitted to a service hosted on Cloudflare Workers. That service processes the arguments and returns results to the requesting host. A read-only tool still receives the arguments sent to it.

ChatGPT processes conversations, files, and tool results under the applicable OpenAI terms, account settings, agreements, and privacy practices. See OpenAI’s Privacy Policy. This policy does not replace those practices or establish OpenAI’s retention periods.

3. Tool inputs, purposes, and results

Curated reference lookup

search_sap_references receives a query of 2 to 160 characters. It matches the query against a small, fixed catalog embedded in the application and returns matching reference identifiers, titles, tags, URLs, and notes. It does not perform live web search or fetch the referenced webpages.

Architecture pattern lookup

get_integration_architecture receives one scenario identifier: idoc-to-b2b, successfactors-to-identity, or api-to-agent. It returns a curated pattern, implementation steps, security considerations, a caveat, and a reference link. It does not retrieve employee information or access customer systems.

Static code checks

review_integration_code receives a language selection, Groovy or XSLT, and code text of 1 to 10,000 characters. It applies limited string-pattern heuristics and returns findings and limitations. It does not compile, execute, transform, or certify the code. Its current application output does not reproduce the submitted code text.

Use redacted or synthetic examples. Do not submit passwords, API keys, access tokens, private keys, government identifiers, payment-card information, health records, employee records, or confidential production data. The tools do not need these data categories.

4. Recipients and other uses

Cloudflare processes MCP requests as the hosting and network infrastructure provider. The requesting host receives tool results to support its response. The publisher and the support email provider process information you send directly for support.

The reviewed application code has no outbound website or API requests, external AI inference calls, advertising, tracking, profiling, sale-of-data functionality, or model-training functionality. It does not connect to customer SAP tenants or perform production changes. These statements describe the application and do not override infrastructure providers’ or the requesting host’s own terms and practices.

If you open a returned reference link, the destination website processes that visit under its own policy. GitHub hosts the source repository; the reviewed application has no functionality that uploads tool inputs or code snippets to GitHub.

5. Application storage and infrastructure retention

The reviewed application processes tool arguments to construct a response and does not implement persistent storage of query text, submitted code, or tool outputs. Its checked-in configuration has no database, KV, object-storage, or Durable Object bindings. No explicit console logging is implemented in the application.

The Cloudflare dashboard reviewed for this Worker shows Workers Logs and Workers Traces disabled. Disabled application logging does not establish that all infrastructure metadata or security records are unretained.

Cloudflare supplies operational metrics such as request counts, errors, and CPU usage even when Workers Logs and Traces are disabled. Its documentation states that Worker metrics can be inspected for up to three months. The publisher does not implement application storage of tool inputs or results, and does not enable additional logging or exports.

Cloudflare may separately process IP addresses, routing information, and other network or security metadata to operate and protect its services. Provider-controlled retention depends on the data category, service purposes, and legal obligations described in Cloudflare’s Privacy Policy; this policy does not promise that Cloudflare retains no data. See also Cloudflare’s Worker metrics documentation.

6. Website visits and support

Opening Agentic Integration Hub webpages is separate from invoking MCP tools. If you contact the publisher, your email address, message, and any attachments are used to respond to your inquiry and resolve reported issues.

The website is configured for Cloudflare Pages and uses Cloudflare’s delivery and security infrastructure. The reviewed website source does not implement tracking cookies, advertising trackers, third-party visitor analytics, local storage, session storage, or a contact-submission form. Its navigation, search filters, and browser developer utilities run locally in the browser; these utilities are separate from the remote MCP tools described above.

The inspected live homepage includes Cloudflare email-address obfuscation and network-error reporting headers. Cloudflare may therefore process technical request and network-error metadata for delivery, reliability, and security, including IP addresses and routing data as described in its privacy policy. A network-reporting configuration lifetime is not a data-retention period. The publisher does not enable additional application-level website logging or analytics. No tracking cookie was set in the inspected homepage response; this observation is not a guarantee about every provider response or security challenge.

Support is provided by email at contact@agenticintegrationhub.com, rather than a website contact form. The domain’s mail records direct incoming mail to Hostinger. Email content and attachments are processed by the email service and, if configured, any forwarding destination used by the publisher. The website and MCP repositories do not determine mailbox retention.

Support messages and attachments are retained in the support mailbox until the publisher manually deletes them. There is no automatic deletion schedule or fixed retention period for that correspondence. Copies retained by the email provider, including deleted-item recovery or backups where applicable, follow the provider’s service practices; manual mailbox deletion does not establish immediate removal from every provider system.

Support is provided on a limited, best-effort basis. Not every inquiry receives a response, and no response time or service-level commitment is guaranteed. For access, correction, or deletion requests, contact the publisher through the contact page and identify the relevant correspondence without resending confidential material. These requests remain subject to applicable legal obligations.

7. Your choices and requests

You choose what information to submit and can remove unnecessary details before a remote tool is invoked. You can stop using or remove the plugin to stop future use through that installation. Removing it does not automatically delete independently held support correspondence or infrastructure records.

Use the contact page to request information about, correction of, or deletion of personal information held by the publisher. Provide enough information to locate the interaction, such as its approximate date, without resending confidential material. Limited identity verification may be needed. Support correspondence has no automatic deletion schedule; provider-controlled records and any applicable legal retention requirements may limit immediate deletion.

For ChatGPT conversation, file, and account data, use OpenAI’s available account controls and support. Deleting a ChatGPT conversation does not by itself request deletion of independently retained publisher or provider records.

8. Security and updates

The MCP service uses HTTPS. Its tool inputs are bounded by schemas, and it implements read-only functions without production writes or code execution. These controls are not a security certification or a reason to submit sensitive production data.

We will update this policy when service data practices change and display the revised effective date. Questions can be directed through the contact page.
