What the plugin helps with

  • Enterprise agent integration and API-to-AI architecture.
  • MCP clients, servers, tool contracts, gateway policies, discovery, and routing.
  • Multi-agent orchestration, security, observability, and recovery patterns.
  • SAP and non-SAP integrations, with implementation guidance and code examples.

What to include in a support request

  1. Use the subject agenticintegrationhub support.
  2. Describe what you were trying to accomplish and which AI host you used.
  3. Include the plugin or skill version, if visible, and relevant protocol, SDK, or platform versions.
  4. Provide a short, redacted prompt or example and explain the expected and actual results.
  5. Include sanitized error text, reproducible steps, and whether the issue occurred in a test or production environment.

Do not send passwords, API keys, access tokens, private keys, personal employee data, financial records, or confidential customer payloads. Use synthetic examples. Redact account identifiers and URLs where necessary.

Privacy and security concerns

Send privacy requests or suspected security issues directly by email. Use the subject agenticintegrationhub privacy request or agenticintegrationhub security report. Describe the concern without sending live credentials or sensitive records. Do not publish confidential details in public GitHub discussions or issues.

For ChatGPT account access, billing, conversation deletion, or host-specific failures, use the AI host’s own support. The publisher cannot administer your host account or enterprise tenant.

Current capabilities and limits

The current release is skills-only. It does not include a publisher-operated MCP endpoint, a live gateway/router, enterprise-system authentication, automated deployment, or production monitoring. A diagram or code example is not evidence that a service has been deployed or tested in your environment.

If an answer refers to “MACP” or another ambiguous protocol, specify the intended project and version. Ask for official references and verify version-sensitive guidance against the relevant specification.

Support availability

Support is provided on a limited, best-effort basis. Responses, fixes, response times, continuous availability, and service-level commitments are not guaranteed. Support correspondence is handled as described in the Privacy Policy.
