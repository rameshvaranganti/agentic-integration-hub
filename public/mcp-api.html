Current specifications

Check these versions before you read any MCP or A2A tutorial. Material written before mid-2026 often describes sessions, server-initiated sampling and the older A2A message names.

SpecificationCurrent versionNotable
Model Context Protocol2026-07-28Stateless core; no initialize or Mcp-Session-Id; Multi Round-Trip Requests; Mcp-Method / Mcp-Name headers; Roots, Sampling and Logging deprecated
Agent2Agent (A2A)v1.0 (v1.0.1 patch)JSON-RPC, gRPC and HTTP+JSON bindings; signed Agent Cards; tenant field; renamed operations (SendMessage, GetTask)
MCP authorizationOAuth 2.1 profileProtected Resource Metadata, resource indicators, iss validation; Client ID Metadata Documents preferred over Dynamic Client Registration
