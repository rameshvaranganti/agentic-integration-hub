Patterns that carry over from classic integration

Agentic situationIntegration pattern
Agent retries a write after a dropped streamIdempotent receiver with idempotency keys
Step 3 of 5 fails after an agent posted documentsSaga with compensating actions
A2A task runs for hoursAsynchronous request-reply with correlation ID and status endpoint
Agent floods a backend with callsThrottling, circuit breaker, bulkhead
