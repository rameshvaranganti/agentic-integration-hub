SAP CPI iFlow Builder Privacy Policy

Effective date: October 27, 2026. This policy describes the current skills-only release of SAP CPI iFlow Builder. It will be updated before introducing hosted MCP processing or repository publishing.

1. Who operates this plugin

SAP CPI iFlow Builder is an independent project created by Rameshkumar Varanganti through Agentic Integration Hub. It is not an official SAP or OpenAI product and is not affiliated with or endorsed by either company. Questions about this policy may be submitted through the contact page.

2. Information you may provide

While asking for integration design help, you may choose to provide package and iFlow names, adapter settings, endpoint descriptions, process requirements, Groovy scripts, XSLT mappings, XML or JSON examples, error messages, or SAP-exported design-time ZIP files.

Do not include passwords, API keys, OAuth secrets, private keys, production credentials, personal data, or confidential records. Replace sensitive configuration values with placeholders or SAP credential aliases.

3. How the current release works

The currently available plugin is skills-only. It provides design guidance and includes local generator source code for optional use outside the ChatGPT plugin. It does not currently run a publisher-operated remote MCP service, independently access SAP Cloud Integration tenants, automatically generate downloadable ZIPs inside ChatGPT, or write to Git repositories.

Prompts and files provided through ChatGPT are handled according to OpenAI's applicable terms, privacy practices and account settings. Please see OpenAI's Privacy Policy. This page does not replace those policies.

4. Integration artifacts and source code

The skills-only plugin does not independently maintain a publisher-operated database of your SAP integrations, generated files, prompts, or conversations. If you run the bundled generator on your own computer, the files it processes are handled in that local environment, subject to your own configuration and security controls.

Users remain responsible for inspecting generated configurations and testing artifacts in an appropriate non-production SAP environment before deployment.

5. SAP reference content

The plugin may direct users to SAP documentation and SAP Business Accelerator Hub. Access to and use of SAP-provided integration packages are governed by SAP's applicable licensing, access and usage terms. The plugin does not claim ownership of third-party materials.

6. Website and support inquiries

If you contact Agentic Integration Hub, details you voluntarily submit, such as your contact information and message, may be used to respond to your request. Website hosting and security providers may also process technical request information, such as IP addresses and server logs, depending on the site's actual setup. This policy does not promise a particular hosting-log retention period.

7. Sharing, retention and deletion

The current skills-only plugin does not independently sell user information, collect payments, or store a separate database of ChatGPT conversations. ChatGPT content retention and deletion are governed by OpenAI's applicable policies and controls. To request information about a message sent directly through this website, use the contact page.

8. Future MCP and Git features

Planned features include hosted iFlow ZIP generation, optional SAP integration connectivity, and authorized Git repository publishing. These features are not active in the current skills-only version. Before they are offered, this policy must be updated to explain the actual data transferred, service providers involved, authentication, storage, retention, deletion and user authorization controls.

9. Changes and contact

We may revise this policy as the product evolves. An updated effective date will be shown when changes are published.
