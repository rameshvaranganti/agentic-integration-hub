Open problems in 2026

Questions the protocols and standards do not yet fully answer, and where integration practice is still forming.

Open problem

Multi-hop delegation

OAuth handles one hop well. Chains of agents across organizations and asynchronous pauses still lack a settled pattern for preserving the original user's authority and narrowing it at each hop.

Open problem

Tool selection reliability

Models choose tools from names and descriptions. How to write, test and version tool descriptions so the right tool is chosen consistently is largely empirical today.

Open problem

Approval fatigue

Human approval is the most common safeguard and the easiest to weaken. Open question: which actions truly need a person, and how to show approvers evidence rather than an agent's summary.

Open problem

End-to-end agent observability

Tracing a request from an agent conversation through gateways, integration flows and systems of record, with OpenTelemetry context and without logging personal data.

Open problem

Retries in a stateless protocol

With stateless MCP and unresumable streams, retries become routine. Making every agent-reachable write idempotent across legacy systems is an engineering gap in many landscapes.

Open problem

Evidence for regulation

What logs, approvals and traceability records integration layers must produce so organizations can demonstrate oversight of high-risk AI uses such as HR decisions.
